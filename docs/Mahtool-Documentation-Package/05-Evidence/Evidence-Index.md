## Safe-use notes

No environment/default credential values, private audio, user transcript or unapproved profile/contact figures are included. Production text snippets are deliberately selected, not a complete archive. Links into source identify evidence without reproducing sensitive literals. Registry advisory URLs come from npm audit and were not independently exploited or validated upstream. Public drafts should never copy internal raw security/testing output wholesale.

The user authorized repository storage and a push on the existing working branch after external artifacts failed to persist. This edition is therefore stored in docs/Mahtool-Documentation-Package, rather than claiming that an absent earlier ZIP was pushed.
